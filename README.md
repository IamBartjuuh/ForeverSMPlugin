# ForeverSMPlugin
This plugin is build by IamBartjuuh and specifically made to stop being dependent on other plugins after a update (drop). 

Profiles: since the server is made for an SMP and meant to last forever. People need to be able to switch profiles. with /profile your can save different profile and load different profiles.
## Commands
- /profile (save|load) - Save your current user data and load your current user data.
